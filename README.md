# onaks_system

Sistema de pedidos B2B para una distribuidora: catálogo y compra para los clientes, y gestión de pedidos,
reparto, stock y compras para la distribuidora.

- [Roadmap](ROADMAP.md): fases, decisiones y estado.
- [Instalación en producción](docs/instalacion.md): servidor con Docker, HTTPS con Caddy y backups.
- [Manual técnico](docs/manual-tecnico/README.md): arquitectura, entornos de desarrollo y producción, base de
  datos, funcionamiento de cada módulo, testing y cómo programar sobre el sistema.
- Desarrollo: el código está en `app/` (ver `CLAUDE.md` para un resumen de la arquitectura y los comandos).
