# onaks_system

Sistema de pedidos B2B para una distribuidora: catálogo y compra para los clientes, y gestión de pedidos,
reparto, stock y compras para la distribuidora.

B2B ordering system for a distributor: catalog and purchasing for customers, and order, delivery, stock
and purchasing management for the distributor.
